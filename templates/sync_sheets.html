Architectural Integrity

Why one-way synchronization? In an academic relational DBMS, MySQL serves as the single source of truth enforcing strict 3NF normalization, foreign keys, and CHECK constraints.

Exporting to Google Sheets provides department coordinators with readable reports, spreadsheet formulas, and external distribution without compromising database integrity or permitting unsanitized direct writes.

Step-by-Step Google Sheets Configuration Guide

1. Enable Google Sheets API

Open the Google Cloud Console, create a project, and enable the Google Sheets API and Google Drive API.

2. Create Service Account & Download Key

Navigate to IAM & Admin > Service Accounts, create a new service account, generate a JSON Private Key, and save the downloaded file as:
Student_Progression_DBMS_Project/credentials/service_account.json

3. Share Spreadsheet with Service Account

Create a new Google Sheet at sheets.new. Click Share and grant Editor permissions to the service account client email (found inside the JSON key as client_email).

4. Set Environment Variables in .env

Extract the sheet ID from the spreadsheet URL:
https://docs.google.com/spreadsheets/d/<SPREADSHEET_ID>/edit
Add to your local .env file or use the Connect / Edit Sheet ID button above: 

GOOGLE_SHEET_ID=your_spreadsheet_id_here
GOOGLE_CREDENTIALS=credentials/service_account.json
